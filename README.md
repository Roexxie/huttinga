# Websitevoorstel Huttinga Allround Service

Presentatieversie van een websitevoorstel voor Huttinga Allround Service (Wekerom).
Dit is **niet** de officiële website van het bedrijf; die staat op [huttinga-allroundservice.nl](https://huttinga-allroundservice.nl/).

- De pagina staat op `noindex` en wordt niet door zoekmachines opgenomen.
- De foto's zijn tijdelijke sfeerbeelden via Unsplash, geen projecten van Huttinga Allround Service.
- De vakken F1 t/m F6 tonen waar eigen foto's komen.

Bij livegang: presentatiebalk, fotoplekken en `noindex` verwijderen, eigen foto's plaatsen en het formulier koppelen aan een formulierdienst.
